# Симуляция банкомата (ATM Simulator)

## Постановка задачи

Реализовать консольное приложение, которое имитирует работу банкомата. Программа должна позволять пользователю:

1. **Авторизоваться** по номеру карты и PIN-коду.
2. **Проверить баланс**.
3. **Внести деньги** на счёт.
4. **Снять деньги** (с проверкой достаточности средств).
5. **Перевести деньги** другому пользователю по номеру карты.

## Использованный паттерн

**Singleton** (Одиночка)

### Цель применения
Гарантировать, что в приложении существует **только один экземпляр банкомата**. Это важно, потому что:
- Банкомат — это физическое устройство, у которого не может быть нескольких копий одновременно.
- Все операции (проверка баланса, снятие, перевод) должны выполняться через единую точку управления.
- Предотвращается случайное создание нескольких объектов `ATM`, что могло бы привести к путанице с данными пользователей.

### Какую задачу решает
Паттерн Singleton скрывает конструктор класса (`private ATM()`) и предоставляет статический метод `GetInstance()`, который всегда возвращает один и тот же объект. Это гарантирует, что данные о пользователях и их балансах не размажутся по разным объектам.


### Требования
- .NET SDK (6.0 или новее)
